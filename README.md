# Check AV Exclusions

The program will check if the NIT antivirus Exclusions is set and will show a popup message if not.

Программа проверяет, установлены ли исключения антивируса для NIT, и показывает всплывающее окно, если этого не происходит.

Пакет состоит из двух частей:

1. Программы проверки исключений в текущей папке `CheckExclusionsHere`.
2. Программы проверки установленных исключений `NIT.theREg`.

Описание к ним смотри в файлах `README`
