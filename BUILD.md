# BUILD Подготовка дистрибутива

## Системные требования

Сборка данной программы происходила на компьютере с установленной Windows 11 Pro.

Система должна устанавливаться на компьютеры с операционной системой Windows 6.1 SP1+ и архитектурой amd64.

В качестве среды разработки использовалась Visual Studio 2017 Community, в качестве программы для сборки инсталлятора —  InnoSetup. Обе эти программы загружены из менеджера пакетов chocolatey.

## Сборка CheckExclusionsHere

1. Перейдите в каталог `CheckExclusionsHere`.
2. Откройте в нём файл с расширением `*.sln` в редакторе Visual Studio IDE.
3. Отредактируйте параметры сборки.
4. Выберите пункт: "Пересобрать решение".
5. Найдите скомпилированный файл и перенесите его в `NIT.theREg\C\pub1\Util\NIT.theReg`

## Сборка NIT.theReg

1. Найдите в каталоге `NIT.theReg` файл с расширением `*.iss`.
2. Откройте его в редакторе InnoSetup.
3. При желании измените его метаданные.
4. Скомпилируйте файл. Результирующий файл окажется в папке `NIT.theReg\Output`.
5. Загрузите полученный файл на хостинг. Пользуйтесь.
