# NIT.theReg

A Program for checking if the antivirus exclusions is set on a Windows computer.

Программа проверяет, установлены ли определённые исключения антивируса на компьютере с Windows.

## Введение

Программа проверяет, установленны ли специфические исключения антивируса на компьютере под управлением операционной системы Microsoft Windows для продуктов New Internet Technologies. В случае обнаружения исключения информация о нём (установлено/неустановлено) копируется в соответствующие ветви реестра Windows.

## Описание работы

Программа написана на основе командных файлов. Также используются бинарные программы `chkadmin.exe` и `CheckExclusionsHere.exe`. Последняя программа может вызывать срабатывание антивируса (хотя в ней нет вредоносного кода), но это никак не отражается на функциональности программы — невозможность запуска `CheckExclusionsHere.exe` говорит о том,что не все исключения установлены на компьютере.

При своей работе программа ничего не выдаёт (в случае успеха) или выдаёт сообщения о срабатывании антивируса (в случае отсутсвия исключений).

В случае, если на компьютере установлены не все исключения, появляется диалоговое окно с сообщением об ошибке. В нём будет на выбор два пункта — закрыть програму или попытаться установить переменные окружения. При выборе второго пункта открывается окно с опцией приостановки Windows Defender и окна браузера с инструкцией по ручной установке исключений в популярных антивирусах.

Программа для своей работы требует установку VC++ Redistributible and Runtime 2015+ (проверяется перед запуском).

Программа предназначена только для проверки условий запуска и установки продуктов New Internet Technologies, Inc после начальной инициализации программы установки компонентов. Используется она только для проверки установленных программой инсталляции продуктов NIT необходимых настроек и исплавления неисправностей в этих настройках. Сама по себе она не очень полезная.

## Запуск программы

Программа запускается сразу же после установки. Для повторного запуска скопируйте следующую команду в окно терминала  Windows и нажмите «Enter».

```bash
c:\pub1\Util\NIT.theReg\nit.Init.Run.bat
```
## Установка программы

1. Загрузите с сайта программ NIT файл `theRegSetup.exe`
2. Запустите его двойным щелчком и следуйте указаниям мастера установки, или
3. Введите в командной строке команду для «тихой» установки:
```bash
theRegSetup.exe /VERYSILENT /NORESTART
```
4. Для удаления программы запустите файл: `c:\pub1\Util\NIT.theReg\uninst00.exe`. Программа полностью удалится с компьютера.
