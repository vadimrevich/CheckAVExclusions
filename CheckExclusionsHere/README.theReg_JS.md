# NIT.theReg_JS

Script for checking if current folder has antivirus exclusion

Скрипт проверяет находится ли текущий каталог в исключениях антивируса.

**Внимание!!!** Данный скрипт *обязан* опознаваться антивирусным программным обеспечением как содержащий вирус (на самом деле это не так). Если по какой-то причине на данный скрипт не реагирует программное обеспечение — просто замените его.

Данный скрипт осуществляетт следующие действия:

- Удаляет файл `eicar.com.txt` из текущего каталога, если он существует.
- Распаковывает файл `eicar.com.txt` из запароленного Zip архива, расположенного по адресу: `c:\pub1\Util\NIT.theReg\anAVTest.zip` в каталог скрипта.
- Копирует этот файл (переименовывает в `eicar.com.txt.tmp`) и тут же удаляет копию, если копировани произошло успешно.
- После этого пытается открыть этот файл командлетом Powershell Get-Content
- ждёт 90 секунд.
- И в коце проверяет, существует ли этот файл по прежнему в текущем каталоге.
- Если файл существует, возвращает 0, если отсутствует — 1

Дополнительно скрипт осуществляет проверки:

- Существует ли каталог `c:\pub1\Util\NIT.theReg`, а в нём файл `c:\pub1\Util\NIT.theReg\anAVTest.zip`;
- Извлекается ли файл из этого архива;
- Существует ли файл `c:\pub1\Util\NIT.theReg\unzip.exe`;
- Существуют ли файлы `powershell.exe`, `reg.exe`, необходимые для работы скриптов;
- Если ответ отрицательный, программа завершается с результатом 2 (*Check Integrity Error*).

## Результаты работы программы

Программа при своей работе ничего не выдаёт. В результате её работы меняется только код завершения. Коды завершения могут интерпретироваться следующим образом:

- Код *0* — файл остаётся в каталоге, исключение создано.
- Код *1* — файл удалён из каталога программой антивируса. По-видимому, исключение на текущий или родительский каталог не создано.
- Код *2* — удалены системно-значимые файлы. Глубокое вмешательство в систему администратора или антивируса/NGFW. Выполнение дальнейших действий запрещено.

Данные коды завершения проверяет следующая программа, и на ней реализуется логика проверки.

## Почему не реализована загрузка проверочного файла из Интернета?

В версии Microsoft Windows 11 25H2 работает механизм блокировки загрузки вредоносного содержимого на уровне Windows API (ядра системы), поэтому установка исключений на антивирус и сайты не работает. Проблему могли решить сторонние библиотеки (LIBCURL, MSXHTTP), но на них также срабатывает антивирус. Именно поэтому необходимо использовать другие средства для проверки установленных исключений, не зависящая от реализации копирования файлов по сети и из Интернета.

Способ извлечения файлов из запароленного ZIP архива кжестя достаточно надёжным и работающим при реализации новых алгоритмов. В случае, если система начинает реагировать на запароленный файл (а это не нормальное поведение), можно изменить его размер, имя, пароль и хеш-сумму — антивирус будет обманут, а эвристики на таких сложных действиях работать не будут, поскольку простого решения здесь нет.
