# Check Exclusions Here

Program for Checking if Current Directory have been Placed at any Antivirus Exclusions List

Программа для проверки входит ли текущий каталог программы в исключения любого антивируса.

## Введение и алгоритм работы

Программа представляет собой бинарный исполняемый файл `CheckExclusionsHere.exe`, который запускается в проверяемом каталоге. При запуске программа ничего не выводит, и возвращает код завершения (`%errorlevel%`): *0* — если каталог находится в исключениях антивируса или антивирус не установлен; *1* — каталог не находится в исключениях антивируса.

При своей работе программа загружает с сайта Kaspersky Lab тестовый текстовый файл, содержащий «мнимый вирус» `eicar.com`, пытается его скопировать и открыть. На такие «подозрительные действия» обязан среагировать любой антивирус, и, в конце-концов, происходит ошибка в открытии этого файла, которую перехватывает алгоритм работы. программы. У пользователя при отсутствии исключения на папку появляются сообщения о «заражении» компьютера, и больше ничего. Алгоритм написан так, что, кроме предупреждения антивируса и кода возврата, программа ничего не выводила.

Программа требует установленного в системе VCRedist2022.

Данная программа используется «как есть». Авторы не несут ответственность за прямой или косвенный ущерб, который может произойти из-за неправильного использования программы, ошибок в алгоритме программы.

Данная программа вызывает срабатывания активной защиты антивируса, и сама может определяться антивирусом как «malware». Это является её нормальным поведением. Программа не содержит вредоносного кода, распространяется с открытым исходным кодом.
